# Роль 2: UI

Ты отвечаешь за внешний вид. Сначала прочитай `CLAUDE.md`, `ROADMAP.md` и `src/types.ts`.

**Ветка:** `feat/ui`
**Твои файлы:** `src/components/**`, `src/styles/**`, `src/dev/**`.

## Референс
Внешний вид чата https://web.max.ru/ (открой в браузере, если доступен): светлая тема, сайдбар со
списком чатов слева, окно переписки справа, пузыри сообщений (свои справа, акцентные; чужие
слева, серые), поле ввода снизу. ТЗ: «максимально просто, минимальный набор функций», поэтому не
перегружай интерфейс. Шрифт системный.

## Что сделать
Все компоненты **чисто презентационные**: данные и колбэки приходят через props, стор и API не
импортировать. Стили в CSS Modules, дизайн-токены (цвета, радиусы, отступы) в CSS-переменных в
`src/styles/tokens.css`, сброс стилей в `src/styles/global.css`.

1. `LoginForm`: поля `apiUrl` (по умолчанию `https://api.green-api.com`), `idInstance`,
   `apiTokenInstance` (type=password с кнопкой «показать»), кнопка «Войти».
   Props: `onSubmit(credentials)`, `loading`, `error?: string`. Простая валидация на пустые поля.
2. `Sidebar`: шапка (название Greenline, кнопка «Новый чат», кнопка «Выйти»), список `ChatListItem`
   (аватар-инициалы, заголовок, превью последнего сообщения, время, бейдж непрочитанных, активный чат подсвечен).
3. `NewChatDialog`: поле номера телефона, кнопки «Создать» и «Отмена», сообщение об ошибке.
   Props: `open`, `onSubmit(phone)`, `onClose`, `error?`. Закрытие по Esc.
4. `ChatWindow`: шапка с заголовком чата, лента `MessageBubble`, `MessageInput`. Пустое состояние
   «Выберите чат или создайте новый».
5. `MessageBubble`: текст с переносами и длинными словами, время HH:MM, статус для исходящих
   (pending — часики, sent — галочка, failed — красный значок с подсказкой).
6. `MessageInput`: textarea с авторостом, Enter отправляет, Shift+Enter переносит строку, кнопка
   отправки неактивна для пустого текста.
7. Автоскролл ленты вниз при новом сообщении.
8. Адаптив: при ширине меньше 768px показывается либо список, либо чат, с кнопкой «назад».
9. Доступность: семантические кнопки, `aria-label` у иконок, видимый focus.
10. **Dev-витрина** `src/dev/Showcase.tsx` на моковых данных, где видны все компоненты и состояния
    (ошибка логина, пустой чат, pending/failed-сообщения, длинные тексты). Ревьюер откроет её,
    временно подключив в `main.tsx` (сам `main.tsx` не правь), поэтому опиши в отчёте, как её запустить.

Иконки делай inline SVG, без библиотек.
